# Portfolio photo

The About section uses `asen-mayuranga.jpg`, a copy of the uploaded portrait with a web-friendly filename. The original WhatsApp upload is preserved in this folder.

The portrait keeps its original quality and uses a responsive 4:5 frame. Its position is set in `.portrait-frame img` in `styles.css`. It loads lazily, with dimensions reserved to keep the surrounding content stable.

To replace it later, add a new portrait using the same filename or update the image path and dimensions in `index.html`.
